# TomServer 문서

Kotlin + Spring Boot 기반 스페셜티 커피 플랫폼.

생두에서 한 잔까지의 가치사슬 — 생두 유통, 로스팅, 볶은 원두, 커피 — 을 다루는 서버다.
실서비스 운영이 아니라 백엔드 난제 — 쓰기 경합, 정합성, 읽기 확장 — 를 직접 겪는 것이
목적인 연습 프로젝트이며, 한정 드롭 판매 → 공동구매·정산 → 팔로우 피드 순으로
한 축씩 쌓는다. 범위와 순서는 [로드맵](roadmap.md)에 있다.

- [아키텍처 결정 기록](adr/) — 각 결정의 배경과 근거, 그리고 **기각한 대안**

- [1단계 학습 과제](phase1-tasks.md) — 현재 과제와 성공 기준
- [개발 환경 시작하기](getting-started.md) — 기술 스택, 빌드·실행·테스트, 프로젝트 구조, 의존성 추가 방법
- [개발 규약](conventions.md) — 패키지 구조, 브랜치, 커밋 메시지, 테스트
